# منصة المدرسة — School Management Platform

منصة إلكترونية متكاملة لإدارة مدرسة مصرية (ابتدائي/إعدادي/ثانوي)، مبنية لتُنشر
مجانًا بالكامل على Cloudflare.

## الستاك التقني
- **Frontend:** React + Vite + Tailwind (Cloudflare Pages) — **PWA حقيقية تعمل دون اتصال**
- **Backend:** Hono على Cloudflare Workers
- **Database:** Cloudflare D1 (SQLite) + Drizzle ORM
- **تخزين الملفات:** Google Apps Script + Google Drive (بديل مجاني عن R2)
- **العمل دون اتصال:** Service Worker (vite-plugin-pwa) + IndexedDB لتخزين القراءة ومزامنة الكتابة تلقائيًا
- **CI/CD:** الفرونت يُنشر تلقائيًا عبر ربط Cloudflare Pages المباشر بـ GitHub (بدون wrangler)؛
  الـ Worker والنسخ الاحتياطي عبر GitHub Actions (يتطلبان wrangler)

## هيكل المشروع
```
frontend/   الموقع العام + كل لوحات التحكم (React SPA)
worker/     الـ API (Hono) + مخطط قاعدة البيانات (Drizzle) + migrations D1
gas/        كود Google Apps Script (تخزين ملفات + توليد شهادات PDF)
docs/       المعمارية، ERD، مصفوفة الصلاحيات، سير عمل الامتحانات، دليل الإعداد
```

## البدء السريع
راجع [`docs/SETUP.md`](docs/SETUP.md) — دليل **شامل خطوة بخطوة من الصفر** (14 قسمًا،
من إنشاء الحسابات وحتى النشر الفعلي والتحقق النهائي)، لا يفترض أي خبرة سابقة
بـ Cloudflare أو Google Apps Script أو GitHub Actions.

## حالة المشروع (Phases)
- [x] Phase 0 — المعمارية والوثائق
- [x] Phase 1 — الهيكل الأساسي (D1 schema, Worker skeleton, Auth, GAS, Frontend shell)
- [x] Phase 2 — استكمال Auth/RBAC الكامل (me/refresh/change-password/forgot-password عبر Gmail)
      + صلاحيات دقيقة (permissionMiddleware) + إعدادات المدرسة الكاملة + إدارة المستخدمين والأدوار
      + AuthContext وحماية المسارات فعليًا في الفرونت
- [x] Phase 3 — الموقع العام الكامل (رئيسية، عن المدرسة، المراحل، الأخبار، تواصل معنا)
      + إحصائيات حقيقية من D1 + تقويم دراسي + CMS كامل للأخبار/الإعلانات (نشر/أرشفة) + الأنشطة
      + تم التحقق من نجاح `npm run build` للـ Frontend و `tsc --noEmit` للـ Worker بدون أي أخطاء
- [x] Phase 4 — إدارة الطلاب (CRUD + بحث/فلاتر + تسجيل بفصل) والمعلمين (CRUD + تكليف بمادة)
      وأولياء الأمور (CRUD + ربط حقيقي بالأبناء عبر البحث بالكود) + الهيكل الأكاديمي (صفوف/فصول/شعب/مواد)
      + استيراد Excel كامل (تحليل في المتصفح → Preview/Validation من السيرفر → Commit ذرّي عبر D1 batch
      بحيث يفشل الاستيراد بالكامل أو ينجح بالكامل، بدون بيانات جزئية) + إصلاح ثغرة صلاحيات (read مقابل crud)
      + تحسين حجم حزمة الفرونت عبر Lazy Loading لمكتبة xlsx
- [x] Phase 5 — الجداول الدراسية (منع تعارض المعلم/الفصل فعليًا عبر UNIQUE constraints في D1،
      وليس تحققًا شكليًا في الواجهة) + الحضور والغياب (تسجيل جماعي Upsert ذرّي، كشف حضور تفاعلي للمعلم،
      تقارير طالب/فصل مع تحقق فعلي يمنع الطالب/ولي الأمر من رؤية بيانات غير أبنائهم)
      + إصلاح ربط حسابات Demo بسجلاتها الفعلية (كانت بلا ربط، ما كان سيُعطّل صلاحيات "بياناتي فقط")
- [x] **Phase 6 — محرك الدرجات + نظام الكنترول الكامل (أهم مرحلة في المواصفات):**
      - محرك درجات ديناميكي بالكامل (`grade_components` + `grade_scale` قابلان للتخصيص من الأدمن دون كود)
      - إدارة امتحانات كاملة: أنواع، مواد مرتبطة، لجان، **توليد أرقام جلوس تلقائي** بلا تعارض
      - **سير عمل اعتماد حقيقي ومُطبَّق بالكامل في الـ API**: Draft→Submitted→Reviewed→Approved→Published→Locked
        مع تحقق صلاحية الانتقال لكل خطوة (ليس فقط إخفاء زر في الواجهة)
      - **بوابة تحقق فعلية قبل الاعتماد**: تمنع الاعتماد إن وُجد طالب بلا درجة، درجة تتجاوز الحد الأقصى،
        أو طالب بلا رقم جلوس — وتُرجع قائمة مفصّلة بالمشكلات بدل رفض عام غامض
      - **تعديل استثنائي بعد القفل** لـ `super_admin` فقط، بسبب إلزامي وتوثيق كامل (قديم/جديد/من/متى) لا يُحذف
      - حماية ملكية حقيقية: معلم لا يستطيع إدخال/إرسال درجة مادة غير مُكلَّف بتدريسها لهذا الطالب تحديدًا
      - عرض نتائج محمي للطالب/ولي الأمر (منشور/مُقفل فقط لأنفسهم، مع دعم تعدد الأبناء لولي الأمر)
- [x] **Phase 7 — الشهادات (PDF عبر GAS) + التحقق بـ QR:**
      - إصدار شهادة فعلي: يجمع النتائج **المنشورة/المُقفلة فقط** لطالب معيّن، يحسب المجموع والنسبة والتقدير،
        ثم يستدعي Google Apps Script فعليًا لتوليد PDF من قالب Google Docs ورفعه لـ Google Drive (بديل R2)
      - رمز تحقق فريد يُصاغ تلقائيًا لكل شهادة، مع **رمز QR فعلي** (مكتبة `qrcode`) يشير لصفحة تحقق عامة
      - `/verify/:code` صفحة عامة **بدون تسجيل دخول** للتحقق من صحة الشهادة (مثل مسح الكود من طرف ثالث)،
        تعرض بيانات كافية للتحقق دون كشف معلومات حساسة
      - عرض شهادات الطالب ضمن صفحة نتائجه، بنفس حماية "بياناتي فقط" المطبَّقة على النتائج والحضور
- [x] **Phase 8 — مركز التقارير + الإشعارات + البحث الشامل:**
      - 3 تقارير حقيقية (كشف طلاب، ملخص نتائج امتحان، أفضل النتائج) مع **تصدير CSV فعلي** يفتح مباشرة
        في Excel (بترميز BOM لدعم العربية) + دعم الطباعة من المتصفح مباشرة
      - إشعارات حقيقية: عند نشر نتيجة، يُنشأ إشعار تلقائيًا للطالب **ولكل** أولياء أموره المرتبطين،
        وليس فقط عند طلب يدوي — جرس إشعارات يعمل فعليًا مع تحديث دوري وتعليم كمقروء
      - بحث شامل حقيقي عبر الطلاب/المعلمين/المواد/الإعلانات في استدعاء واحد، محمي بصلاحيات القراءة
- [x] **Phase 9 — سجل العمليات والنسخ الاحتياطي:**
      - عارض Audit Log كامل مع فلاتر، **للعرض فقط** (لا DELETE ولا PATCH على المسار إطلاقًا مهما كانت الصلاحية)
      - نسخ احتياطي **مجدول فعليًا** عبر GitHub Actions (يوميًا 2:00 صباحًا UTC) يُصدّر D1 بالكامل
        ويرفعه إلى Google Drive عبر GAS، مع تسجيل نتيجة كل تشغيل في `backup_logs` وعرضها في الواجهة
- [x] **Phase 10 — التوثيق والاختبار النهائي:**
      - `docs/API.md`: توثيق كامل لكل مسارات الـ API (21 ملف routes) بصلاحياتها ورموز أخطائها
      - `docs/TESTING_CHECKLIST.md`: قائمة اختبار شاملة (أمان، صلاحيات، سير عمل الكنترول، نسخ احتياطي)
      - تحقّق نهائي متكرر عبر كل المراحل: `tsc --noEmit` (Worker) و`npm run build` (Frontend) — **صفر أخطاء**
- [x] **إضافة لاحقة — العمل دون اتصال (Offline-First) + مزامنة تلقائية:**
      - PWA حقيقية (Service Worker مبني فعليًا عبر `vite-plugin-pwa`/Workbox) — التطبيق يفتح ويعمل
        بالكامل دون أي اتصال بمجرد زيارته مرة واحدة، ويمكن "تثبيته" كتطبيق مستقل
      - كل قراءة (GET) تُخزَّن في IndexedDB وتُعرض تلقائيًا عند الانقطاع بدل شاشة خطأ
      - كل كتابة (POST/PUT/PATCH/DELETE) تُحفظ في قائمة انتظار حقيقية عند فشل الشبكة، وتُعاد
        محاولتها تلقائيًا وبالترتيب الصحيح فور عودة الاتصال (حدث `online` + فحص احتياطي دوري)
      - استثناء صريح وموثَّق لإجراءات تتطلب استجابة فورية (تسجيل الدخول، إصدار الشهادات) من التأجيل
      - شريط حالة اتصال حي يعرض عدد العمليات المعلَّقة ونتيجة المزامنة لحظيًا
      - راجع [`docs/OFFLINE.md`](docs/OFFLINE.md) للتفاصيل الكاملة وحدودها الصادقة
- [x] **إضافة لاحقة — إزالة كل البيانات الوهمية + تجاوب موبايل كامل:**
      - `migrations/0010_remove_demo_data.sql`: حذف فعلي لكل الطلاب/المعلمين/أولياء الأمور/الامتحانات/
        الأخبار/الحضور الوهمية، مع الإبقاء فقط على البيانات الهيكلية الحقيقية (أدوار، صفوف، مواد،
        جدول تقديرات) وحساب إداري حقيقي واحد بكلمة مرور مؤقتة عشوائية (راجع `docs/INITIAL_ADMIN.md`)
      - الصفحة الرئيسية والموقع العام أصبحا يعرضان اسم المدرسة وبياناتها **الحقيقية** من الإعدادات
        ديناميكيًا، دون أي نص أو تنويه "تجريبي" ثابت في الكود
      - **قائمة تنقل موبايل حقيقية (Hamburger Menu)** للموقع العام — كانت القائمة تختفي بالكامل
        على الشاشات الصغيرة بلا بديل؛ الآن تظهر قائمة منسدلة كاملة الوظائف
      - كل الجداول في لوحات الإدارة (10 صفحات) أصبحت محمية بتمرير أفقي آمن (`overflow-x-auto`)
        بدل كسر تخطيط الصفحة على الموبايل
