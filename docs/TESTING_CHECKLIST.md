# قائمة الاختبار قبل الاعتماد النهائي

استخدم الحساب الإداري الأولي في `docs/INITIAL_ADMIN.md` ثم أنشئ حسابات اختبار
حقيقية بأدوار مختلفة من `/admin/users` لتنفيذ هذه الاختبارات يدويًا بعد النشر
(أو محليًا عبر `wrangler dev` + `npm run dev` في الفرونت).

## المصادقة والصلاحيات
- [ ] بعد إنشاء حساب حقيقي لكل دور من /admin/users، تسجيل الدخول بكل دور ينجح ويوجّه للوحة الصحيحة
- [ ] 5 محاولات دخول خاطئة تقفل الحساب فعليًا (status = locked في D1)
- [ ] GET /api/students بدون تسجيل دخول يرجع 401
- [ ] محاولة وصول حساب دور "معلم" إلى /api/users ترجع 403 وتُسجَّل في audit_logs
- [ ] نسيت كلمة المرور: يصل بريد فعلي (تحقق من صندوق GAS/Gmail) والرابط يعمل مرة واحدة فقط

## CRUD الأساسي
- [ ] إنشاء/تعديل/حذف طالب، معلم، ولي أمر يعمل ويظهر فورًا في القوائم
- [ ] ربط ولي أمر بطالب عبر البحث بالكود ينجح فعليًا (ليس Placeholder)
- [ ] استيراد Excel: ملف به صف خاطئ يُرفض بالكامل (لا استيراد جزئي)؛ ملف صحيح بالكامل يُستورد بنجاح

## الجداول والحضور
- [ ] محاولة إضافة حصتين لنفس المعلم بنفس التوقيت تُرفض بـ 409 SCHEDULE_CONFLICT
- [ ] تسجيل حضور فصل كامل، ثم إعادة تسجيله بنفس التاريخ يُحدِّث القيم (لا يُكرِّرها)
- [ ] طالب يحاول عرض تقرير حضور طالب آخر عبر تعديل الـ ID في الرابط يحصل على 403

## الامتحانات والكنترول (الأهم)
- [ ] إنشاء امتحان ثم ربط مادة ثم توليد أرقام جلوس ينجح ويعرض العدد الصحيح
- [ ] معلم يدخل درجة تتجاوز الحد الأقصى للمكوّن تُرفض بـ 400 SCORE_EXCEEDS_MAX
- [ ] معلم يحاول إدخال درجة لمادة لا يدرّسها لطالب معيّن يحصل على 403
- [ ] الضغط على "اعتماد" مع وجود طالب بلا درجة أو بلا رقم جلوس يُرفض ويعرض قائمة مشكلات دقيقة
- [ ] بعد حل كل المشكلات، الاعتماد ينجح والنتائج تنتقل فعليًا لحالة approved
- [ ] النشر (publish) ينشئ إشعارًا فعليًا للطالب ولكل أولياء أموره (تحقق من جرس الإشعارات)
- [ ] بعد lock، محاولة تعديل الدرجة عبر /entry العادي تُرفض بـ 409
- [ ] PATCH /:id/override بدون super_admin يُرفض بـ 403؛ ومع super_admin بدون reason يُرفض بـ 400

## النتائج والشهادات
- [ ] طالب/ولي أمر يرى فقط النتائج بحالة published/locked، لا يرى draft/submitted
- [ ] إصدار شهادة لطالب بلا نتائج منشورة يُرفض بـ 400 NO_PUBLISHED_RESULTS
- [ ] إصدار شهادة ناجح يُنتج رابط PDF فعلي قابل للتحميل من Google Drive + رمز QR صحيح
